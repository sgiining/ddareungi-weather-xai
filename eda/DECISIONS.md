## 7. 모델링 단계에서 따를 규칙 (결과를 보기 전에 정함, 2026-10-13)

- 설정값 탐색: 조정 단계(2023 학습 → 2024 평가)에서 아래 36개 조합을 시드 5개로 학습해 MAE 평균이 가장 낮은 조합을 고른다.
  - n_estimators {200, 500} × max_depth {None, 8, 16} × min_samples_leaf {1, 3, 5} × 정답 {원래 값, log(1+y)}
  - 로그 변환한 경우에도 MAE는 원래 단위(건)로 되돌려 계산한다.
  - 최저 조합과의 차이가 시드 표준편차 안이면, 정답 원래 값 → n_estimators 작은 것 → max_depth 작은 것 순으로 고른다.
  - B1(달력)과 P(달력+날씨)는 같은 방법으로 각각 고른다. 묶음 제거 실험과 직전 12개월 보조 실험은 P의 설정을 그대로 쓴다.
- 설명 안정성: 평균 절대 SHAP 기준 상위 5개 변수(k = 5)와 상위 3개 날씨 묶음의 Jaccard 지수를 시험 A–B 사이, 시드 5개 사이에서 계산한다.
- 실험 환경(EDA 실행 기준): Python 3.12.3, pandas 3.0.6, numpy 2.5.4, scikit-learn 1.9.1, matplotlib 3.11.2, Windows 10, CPU Intel64 Family 6 Model 142. shap 버전은 설치 후 추가한다.

## 8. 모델링 추가 규칙 (실험 실행 전에 정함, 2026-11-27)

7번 규칙에 아래 내용을 더한다. 조정 단계를 포함한 모든 모델링 결과를 보기 전에 정했다.

- 입력 인코딩
  - 월·요일은 범주를 하나도 빼지 않고 원-핫 인코딩한다(월 12열, 요일 7열). 네 모델(월·요일 평균 제외) 모두 같은 입력 표를 쓴다.
  - 연도는 숫자형 그대로 둔다. 원-핫으로 하면 테스트 연도가 학습에 없는 범주가 되어 모든 열이 0이 되고, 결국 기준 연도(2023년)로 처리되기 때문이다.
  - 주말·공휴일·쉬는 날 여부(0/1)와 날씨 9개는 그대로 둔다.
  - 입력 열 수: B1 23개, P 32개.
  - SHAP은 원-핫 열 값을 더해 월·요일 단위로 해석한다(`experiments/common.py`의 `shap_by_variable`).
- 연도의 의미
  - 조정 단계는 학습 연도가 2023년 하나뿐이라 연도가 설정 선택에 영향을 주지 않는다.
  - 랜덤 포레스트는 학습에 없는 연도를 가장 최근 학습 연도와 같게 처리한다. 즉 시험 A에서 2025년은 2024년, 시험 B에서 2026년은 2025년으로 취급된다. 학습 이후의 수준 변화는 ME와 직전 12개월 학습 실험으로 확인한다.
  - 시험 기간에는 연도가 한 값이므로, 연도의 SHAP 값은 날씨가 아니라 수준 차이로 해석한다.
- max_features
  - 탐색 범위: {1/3, 1/2, 2/3}. 입력 열 수에 대한 비율이다.
  - 1.0(모든 변수 사용)은 랜덤 포레스트가 아니라 배깅이 되므로 범위에 넣지 않는다. 탐색은 108개 조합 × 시드 5개로 한다.
  - 동점일 때의 선택 순서는 7번의 순서 뒤에 min_samples_leaf 큰 것 → max_features 작은 것 → MAE 평균 낮은 것을 덧붙인다.
  - 묶음 제거 실험과 직전 12개월 실험은 P에서 선택한 비율을 그대로 쓴다.
  - 표 8의 변수 선택은 scikit-learn 기본 설정(max_features=1.0)에서 한 상대 비교이며, 다시 하지 않는다.
- SHAP 설정
  - `shap.TreeExplainer(model)` 기본값(tree_path_dependent)을 쓴다. 별도의 기준 데이터는 쓰지 않는다.
  - 시드 5개 모델의 SHAP 값을 평균해 대표 설명으로 쓴다. 이 평균은 시드 평균 예측(표 10의 예측)의 SHAP 값과 같다. 시드별 SHAP 값은 Jaccard 계산에만 쓴다.
  - 정답이 log(1+y)로 선택되면 SHAP 값은 로그 단위로 보고한다. 이때 exp(φ) − 1을 "예측을 약 몇 % 바꿨는지"로 해석한다.
- 기온 반응 곡선(ICE 응용)
  - 가로축은 옮긴 뒤의 최고기온 x이고, 날짜별 일교차 g는 유지한다(최저기온 = x − g).
  - 허용 범위는 max(최고기온 하한, 최저기온 하한 + g) ≤ x ≤ min(최고기온 상한, 최저기온 상한 + g)이다. 하한과 상한은 각 테스트 기간 학습 자료의 관측값이다.
  - 간격은 0.5°C이다.
  - 평균 곡선은 centered ICE로 그린다. 기준점은 학습 기간 최고기온 중앙값이다. x마다 평균에 들어간 날짜 수를 함께 표시한다.
  - 최고기온 35°C 초과 구간은 해석하지 않는다(6번 참고).
- 오차가 큰 날짜
  - 시드 평균 예측의 오차 e에서 기간 전체 중앙값을 뺀다.
  - 강건 z = (e − median) / (1.4826 × MAD)를 구하고, |z| > 3인 날을 선정한다.
  - 선정한 날은 모두 표로 보이고, 개별 SHAP 그림은 과대예측과 과소예측에서 각각 |z| 상위 3일을 그린다(`experiments/analysis_rules.py`).
