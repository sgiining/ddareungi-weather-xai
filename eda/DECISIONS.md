## 7. 모델링 단계에서 따를 규칙 (결과를 보기 전에 정함, 2026-10-13)

- 설정값 탐색: 조정 단계(2023 학습 → 2024 평가)에서 아래 36개 조합을 시드 5개로 학습해 MAE 평균이 가장 낮은 조합을 고른다.
  - n_estimators {200, 500} × max_depth {None, 8, 16} × min_samples_leaf {1, 3, 5} × 정답 {원래 값, log(1+y)}
  - 로그 변환한 경우에도 MAE는 원래 단위(건)로 되돌려 계산한다.
  - 최저 조합과의 차이가 시드 표준편차 안이면, 정답 원래 값 → n_estimators 작은 것 → max_depth 작은 것 순으로 고른다.
  - B1(달력)과 P(달력+날씨)는 같은 방법으로 각각 고른다. 묶음 제거 실험과 직전 12개월 보조 실험은 P의 설정을 그대로 쓴다.
- 설명 안정성: 평균 절대 SHAP 기준 상위 5개 변수(k = 5)와 상위 3개 날씨 묶음의 Jaccard 지수를 시험 A–B 사이, 시드 5개 사이에서 계산한다.
- 실험 환경(EDA 실행 기준): Python 3.12.3, pandas 3.0.6, numpy 2.5.4, scikit-learn 1.9.1, matplotlib 3.11.2, Windows 10, CPU Intel64 Family 6 Model 142. shap 버전은 설치 후 추가한다.
